The numerical experiment fixes the retained v041 BM engine from the canonical v042 archive, with kinetic='none'. The comparison changes only the BM.refine method to the repaired v055 implementation. All Hamiltonian-building source and model parameters remain shared; both variants log identical static Hamiltonian bytes and dimensions. This is a controlled substitute using recoverable historical recipes, not a claim that the engine or native runtime is byte-identical to the original v023 run.

Endpoint recipe: A=-0.30, B=-0.40, T=-1.8, phi=80, ratio=1.1, eps=0.003, N=4/6. It repeats the lower-remote|flat1 portion of lowergap_check.py with grids 24/36, all selected local minima (keep at most eight per grid), return_result=True and explicit reevaluation at returned coordinates. The below-lower gap is excluded from this bounded batch. Finite searches remain numerical searches, not rigorous global bounds.

The observer logs every minimize attempt without altering its inputs/results, the full refinement metadata, returned coordinates/values and independently reevaluated values. The repaired and defective variants are compared within each cutoff; they are not two independent physical implementations. Successful/successful wrapped retries exercise the branch but cannot reveal the stale-success failure that requires differing attempt outcomes. Synthetic tests explicitly cover success/failure, failure/success, both-success and both-failure combinations, nonfinite outcomes, value mismatch and plain-call rejection.

The baseline Euler probe is independent of refinement and logs zero BM.refine calls. The raw euler.py routine uses one 24×40 mesh and returns diagnostics without acceptance. A retained numerical-gate implementation runs 24×40 and 32×56, checking real/Hermitian matrices, eigen-residuals, external isolation on sampled points, orientability, link overlap, sewn-frame norm/overlap and phase resolution. Mesh labels agree. This remains a shared-model/Wilson-method comparison, not independent conceptual or physical validation. Positive sampled external gaps do not establish global isolation.

Only reviewed code executes: the retained BM engine defines its model and imports NumPy/SciPy; selected harmonic/Euler/gate definitions are loaded by AST selection without running historical driver top-level bodies. The selected numerical functions perform matrix construction, eigensolving and optimization; they make no network calls or deletions. The new runner writes only its new result path and captured logs; runtime identity reads installed package metadata/native binaries. The later test runner intentionally starts pytest in one subprocess and writes immutable test artifacts. The package builder creates a new ZIP outside the repository and refuses overwrites.

Source review is bounded to the baseline/scalar/lower-gap drivers, Euler/braid/nodewind/knobs/flat_e2/transfer consumers, relevant log sections, the executed BM/Euler sources and selected numerical-gate definitions. The complete repository is mechanically inventoried only for retained copies of eight named consumers, matching JSON key strings and matching stdout basenames. The source-to-log ledger is contextual; absence of a filename or JSON key does not prove absence of every related result. Arbitrary nested ZIPs and sibling exploratory sweeps were not comprehensively audited.

The logs themselves matter: v029 refuses an Euler-class readout for nonisolated bundles, and v032–v033 revise the e2=0 prediction to undefined when the pair is nonorientable. Those are preserved scientific corrections, even though legacy entry points still print insufficiently gated raw numbers. v056's success-field-consumer correction remains valid; this batch does not reinstate a blanket historical no-impact claim.

All numerical outputs carry a frozen numerical-plan hash and matching before/after runtime identity. Publication checks the preserved prior-tree manifest, current frozen source/documents, rebuilt attribution/measurement reconciliation and a complete source/input/environment-bound test run. Hashes provide internal consistency, not authenticity or chronology. Physical-bilayer validation, global/continuous proofs, N>6 convergence, a microscopic tunnelling strain law and comprehensive dependency security remain outside this batch.
