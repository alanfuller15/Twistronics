## Sparse scope

`CheckedSparse` is intentionally a conservative window API. It enforces a validated explicit fixed basis, candidate/native matrix agreement, native absolute-band comparison, native residuals, orthogonality, subspace agreement and resolved window edges at every acceptance. Missing windows are refusals. LU supplies inverse applications only, never an inertia count. The dense reference adds cost; no acceleration claim is supported.

F01/F02 are implemented within that window mode. The strict pre-construction factory addresses the tested index truncation and basis-identity requirement. The ledger separates disjoint work components from inclusive attempt wall times and retains failures. These statements do not close all of F01–F08 for the earlier atlas/root/event code.
